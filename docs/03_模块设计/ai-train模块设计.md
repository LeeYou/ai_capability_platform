# ai-train 模块设计

## 1. 模块目标

建设训练子系统，提供样本标记、训练任务管理、模型管理和能力元数据管理能力。

## 2. 模块职责

1. 数据集挂载与目录识别
2. 样本标记任务管理
3. 训练任务创建、执行、跟踪
4. 模型产物登记与版本管理
5. 对外提供能力与模型查询 API

## 3. 逻辑组件

1. Web 前端：标注台、训练台、模型管理台
2. API 服务：任务、模型、能力、数据集管理
3. 训练执行器：容器内训练任务调度
4. 能力模板管理器：新增能力模板、训练脚手架
5. 数据持久化层：SQLite + 文件系统

## 4. 核心数据

1. capability_registry
2. dataset_binding
3. annotation_task
4. training_task
5. model_artifact

## 5. 关键流程

1. 扫描 `/data/ai_capability_platform/datasets/`
2. 绑定能力与数据集
3. 创建标注任务并保存结果
4. 发起训练任务
5. 产出部署模型与元数据
6. 发布模型信息给 ai-test、ai-builder 查询

## 6. 接口要求

1. 能力列表接口
2. 模型列表接口
3. 模型详情接口
4. 训练任务创建/查询接口
5. 数据集状态接口

## 7. 非功能要求

1. 支持 CUDA 11.8
2. 支持训练日志持久化
3. 支持任务失败重试和状态跟踪
4. 标注与训练操作审计可追踪

## 8. 设计决策

1. 训练代码采用 Python。
2. 首期训练框架优先 PyTorch。
3. 模型导出统一为部署模型包格式，而非直接交付 checkpoint。
4. 新增能力时必须同步产出训练模板、推理模板、模型 manifest 模板。
