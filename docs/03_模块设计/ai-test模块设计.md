# ai-test 模块设计

## 1. 模块目标

建设模型测试子系统，支持单接口测试、批量测试、测试报告生成与导出。

## 2. 模块职责

1. 从 ai-train 查询模型与能力信息
2. 执行模型测试
3. 生成结构化测试报告
4. 持久化测试结果与报告

## 3. 逻辑组件

1. Web 前端：单测页面、批测页面、报告中心
2. API 服务：模型查询代理、测试任务管理、报告导出
3. 测试执行器：自动匹配能力与推理实现
4. 报告引擎：生成 HTML/PDF/JSON 报告

## 4. 核心数据

1. test_task
2. test_case
3. test_result
4. test_report

## 5. 关键流程

1. 拉取能力与模型信息
2. 用户选择模型与测试集
3. 自动匹配对应推理代码
4. GPU 优先执行，失败时回退 CPU
5. 持久化结果并生成报告
6. 支持导出与追溯

## 6. 接口要求

1. 模型列表同步接口
2. 单接口测试接口
3. 批量测试接口
4. 测试报告查询/导出接口

## 7. 非功能要求

1. 测试执行具备超时控制
2. 测试结果可复现
3. 报告导出稳定可追溯
4. 多能力测试隔离执行

## 8. 设计决策

1. 推理测试采用 Python + ONNX Runtime。
2. 统一测试样本输入抽象，支持图片、视频、PDF、其他文件类型。
3. 报告模板需同时面向研发验收和交付验收。
