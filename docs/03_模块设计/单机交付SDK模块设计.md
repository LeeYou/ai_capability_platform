# 单机交付 SDK 模块设计

## 1. 模块目标

建设面向第三方集成的单机交付方案，提供推理库、头文件、模型包和可选 JNI 封装。

## 2. 模块职责

1. 标准 C/C++ 调用接口
2. 多平台库文件组织
3. 线程安全并发推理支持
4. JNI 封装支持
5. 交付文档与示例接口说明

## 3. 交付内容

1. lib/dll
2. include 头文件
3. 模型包
4. license 文件
5. JNI 库与 Java 接口说明

## 4. 接口原则

1. 生命周期统一
2. 错误码统一
3. 内存所有权清晰
4. 线程安全约束明确

## 5. 平台支持

1. Linux x86_64
2. Linux arm64
3. Windows x86
4. Windows x86_64

## 6. 非功能要求

1. GPU 优先，CPU 回退
2. 并发调用安全
3. 与生产 runtime 协议兼容

## 7. 设计决策

1. 与 ai-builder 产物共享 ABI 标准。
2. JNI 为可选层，不侵入核心推理库。
