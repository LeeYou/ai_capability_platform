# ai-train 开发计划

## 1. 模块目标

落地样本标记、训练管理、模型管理与能力查询能力。

## 2. 工作分解

| 编号 | 工作项 | 状态 |
| --- | --- | --- |
| T1 | 搭建 ai-train 前后端工程骨架 | 已完成 |
| T2 | 接入 SQLite 与宿主机持久化目录 | 进行中 |
| T3 | 实现能力注册与数据集绑定 | 进行中 |
| T4 | 实现样本标记基础功能 | 进行中 |
| T5 | 实现训练任务管理与日志跟踪 | 进行中 |

每次开发前后更新状态、风险、阶段小结。

### 4.2 本轮进行中

第二轮后续阶段已在既有元数据底座之上补齐标注任务、训练任务、模型产物登记与前端骨架，使 ai-train 具备“能力注册 → 数据集绑定 → 标注任务 → 训练任务 → 模型登记 → 管理台承载”的主链路雏形，为训练执行器和前端真实交互继续铺路。
