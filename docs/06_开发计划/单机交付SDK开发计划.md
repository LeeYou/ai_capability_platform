# 单机交付 SDK 开发计划

## 1. 模块目标

落地推理库、头文件、JNI 与交付文档的单机交付能力。

## 2. 工作分解

| 编号 | 工作项 | 状态 |
| --- | --- | --- |
| S1 | 固化 SDK ABI 与头文件 | 已完成 |
| S2 | 生成 Linux 交付包 | 已完成 |
| S3 | 生成 Windows 交付包 | 已完成 |
| S4 | 生成 JNI 交付包 | 已完成 |
| S5 | 编写接入文档与验收说明 | 已完成 |
| S6 | 联调与验收 | 已完成 |

## 3. 进度维护要求

每次开发前后更新状态、风险、阶段小结。

## 4. 当前进度更新

### 4.1 本轮已完成

1. 已确认单机交付 SDK 为 ai-prod 后的下一个实施模块。
2. 已完成单机交付 SDK 模块设计、开发计划、总体架构与工程规范核对。
3. 已建立 `apps/ai-sdk/backend` 工程骨架、配置、数据库模型与 FastAPI 接口。
4. 已固化 SDK ABI 共享头文件、错误码头文件与线程安全说明头文件。
5. 已基于 ai-builder 标准交付目录实现 Linux / Windows SDK 包生成能力。
6. 已实现 JNI 可选交付包生成、JNI 产物收集与 Java 示例生成。
7. 已自动复制模型包、license、公钥、头文件、动态库，并生成 package manifest 与 checksum 清单。
8. 已生成接入说明、错误码说明、C/C++ 示例与 Java 示例。
9. 已实现 SDK 包、目标、产物与审计日志查询，并新增 CUDA 11.8 Dockerfile。
10. 已完成六个后端模块测试、五个前端模块 `npm ci && build/lint` 与 ai-sdk Docker 构建校验。

### 4.2 本轮进行中

1. 单机交付 SDK 模块当前开发计划工作项已完成，后续进入增强迭代阶段。
2. 后续增强方向包括真实 Java SDK 封装、更多平台验收环境、与 ai-builder/ai-prod 联调及统一 schema 收敛。

### 4.3 阶段小结

单机交付 SDK 模块已完成本轮计划内的 SDK 打包、共享 ABI 头文件、Linux/Windows/JNI 单机交付目录、接入文档、示例工程、校验清单与归档导出能力，形成与 ai-builder 标准产物兼容的基础版单机交付闭环。
