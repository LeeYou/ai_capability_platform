按照"上层平台完整、运行底座扎实"的目标分阶段推进平台建设：保留当前平台在内部研发测试流程上的优势，持续完善 Runtime 内核、交付目录与验收体系、生产侧 License / 热更新 / 回滚机制。

## 2. 计划状态说明

- 状态值：未开始 / 进行中 / 已完成 / 阻塞

## 4. 跨模块公共工作项

1. 建立 mono-repo 目录结构
2. 建立前后端基础工程
3. 建立共享元数据协议
4. 建立错误码、manifest、license schema
5. 建立 Docker 基础镜像与挂载目录模板
6. 建立 CI、质量检查与文档更新流程
7. 建立标准 `delivery_package/` 目录规范
8. 建立生产运行底座与内部测试外壳的分层边界

## 5. 进度跟踪要求

1. 每个模块实现前先核对设计文档与模块计划。
2. 实现前更新模块计划实际状态。
3. 实现完成后更新模块计划、总体计划与阶段小结。
4. 提交代码时使用中文提交说明。
5. 每轮实现完成后必须比对设计文档、开发计划与实际代码，确认未跑偏。
