## 文档使用原则

1. 所有设计与实现必须优先对齐产品设计文档与总体架构设计文档。
2. 模块实施前必须同步核对模块设计文档与对应开发计划文档。
3. 开发推进过程中必须持续更新开发计划状态、阶段小结与风险项。
4. 所有文档统一使用 UTF-8 编码，中文表达。
