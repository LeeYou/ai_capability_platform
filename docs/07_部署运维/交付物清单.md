# 交付物清单

## 1. 代码与配置

1. 六个业务模块源码
2. `apps/shared/` 共享 schema、协议与示例
3. `Dockerfile.base.cuda118`
4. `docker-compose.yml`
5. `.github/workflows/` CI 流程
6. `scripts/docker/` 宿主机初始化与健康检查脚本

## 2. 运行期目录

根目录：`/data/ai_capability_platform/`

1. `data/`：数据库、元数据、测试报告、SDK 包工作目录
2. `datasets/`：训练/测试数据
3. `models/`：模型包与 manifest
4. `license/`：license、公钥、签发历史
5. `libs/`：构建交付库
6. `configs/`：运行配置
7. `logs/`：运行日志、审计日志、任务日志
8. `exports/`：报告、构建归档、SDK 归档

## 3. 联调产物

1. ai-train 模型包
2. ai-test 测试报告
3. ai-license-mgr license 文件与公钥
4. ai-builder 多平台构建包
5. ai-prod runtime 装载快照与审计日志
6. ai-sdk 单机交付包、接入说明、示例工程
