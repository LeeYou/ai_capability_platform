# 故障排查指南

## 1. docker compose 启动失败

1. 先执行 `docker compose config`
2. 检查端口 26000-26005 是否冲突
3. 检查 `AI_CAP_HOST_ROOT` 是否为绝对路径

## 2. 服务健康检查失败

1. 使用 `docker compose ps` 查看容器状态
2. 使用 `docker compose logs <service>` 查看日志
3. 使用 `bash scripts/docker/health_check.sh` 逐项验证

## 3. ai-builder / ai-sdk 无法生成产物

1. 确认 `models/` 目录存在目标模型包
2. 确认 `license/` 目录存在标准 `license.bin` 与 `pubkey.pem`
3. 确认 `libs/<target>/<capability>/` 结构满足 `lib/include/license/manifest`

## 4. schema 不兼容

1. 先运行 `python -m unittest discover -s apps/shared/tests -v`
2. 检查示例文件是否仍覆盖所有必填字段
3. 检查 manifest/license 结构变更后是否同步更新共享 schema
