# 08 — 模型包设计

## 8.1 设计原则

1. **不直接交付训练 checkpoint** — 交付"部署模型包"，包含模型文件 + 运行所需全部配置
2. **自描述** — manifest 文件完整描述模型的能力、版本、输入输出、依赖
3. **可校验** — 内含 checksum，加载前可完整性校验
4. **版本化** — 每个版本独立目录，支持多版本共存和回滚
5. **格式统一** — 统一使用 ONNX 格式，通过 ONNX Runtime 执行

## 8.3 manifest.yaml 格式

```yaml
# manifest.yaml — 模型包元信息

# ---- 基本信息 ----
capability_id: "face_detect"
capability_name: "人脸检测"
model_version: "v2"
description: "基于 SCRFD 的高精度人脸检测模型"

# ---- API 兼容性 ----
min_plugin_api_version: "1.0.0"
max_plugin_api_version: "1.99.99"
plugin_id: "face_detect"              # 对应的插件标识

# ---- 模型文件 ----
models:
  - name: "face_detect_model"
    file: "model.onnx"
    framework: "onnx"                 # onnx | tensorrt | openvino
    precision: "fp32"                 # fp32 | fp16 | int8
    sha256: "a1b2c3d4e5f6..."

# ---- 输入规格 ----
input:
  format: "BGR"                       # BGR | RGB | GRAY
  width: 640
  height: 640
  channels: 3
  normalize:
    mean: [104.0, 117.0, 123.0]
    std: [1.0, 1.0, 1.0]
  layout: "NCHW"                      # NCHW | NHWC
  dtype: "float32"

# ---- 输出规格 ----
output:
  type: "detection"                   # detection | classification | feature | ocr
  fields:
    - name: "boxes"
      description: "检测框 [x1, y1, x2, y2]"
    - name: "scores"
      description: "置信度分数"
    - name: "landmarks"
      description: "5点关键点"

# ---- 后处理参数 ----
postprocess:
  nms_threshold: 0.4
  confidence_threshold: 0.5
  max_detections: 100
  
# ---- 阈值配置 ----
thresholds:
  default: 0.5
  high_precision: 0.7
  high_recall: 0.3

# ---- 标签 (分类任务) ----
labels_file: null                     # 无标签文件 (检测任务)

# ---- 性能基线 ----
benchmark:
  device: "NVIDIA A10"
  batch_size: 1
  avg_latency_ms: 15.2
  throughput_fps: 65.8

# ---- 构建信息 ----
build:
  date: "2026-03-20T10:00:00Z"
  training_framework: "PyTorch 2.1"
  export_tool: "torch.onnx.export"
  onnx_opset: 17
  training_dataset: "WiderFace + internal"
  training_epochs: 120
  builder_version: "1.0.0"

# ---- 依赖 ----
dependencies:
  onnxruntime_min_version: "1.16.0"
  opencv_min_version: "4.5.0"
  shared_models: []                   # 无共享模型依赖
```

## 8.4 config.yaml 格式

```yaml
# config.yaml — 运行时配置 (可被宿主机目录覆盖)

# 预处理参数 (通常与 manifest 一致，此处可覆盖)
preprocess:
  resize_mode: "letterbox"            # letterbox | stretch | pad
  input_width: 640
  input_height: 640
  mean: [104.0, 117.0, 123.0]
  std: [1.0, 1.0, 1.0]
  swap_rb: false                      # BGR↔RGB 转换

# 后处理参数 (可覆盖 manifest 中的默认值)
postprocess:
  nms_threshold: 0.4
  confidence_threshold: 0.5
  max_detections: 100

# 阈值 (可在现场根据客户需求微调)
thresholds:
  default: 0.5

# 性能调优
performance:
  enable_fp16: false                  # 是否使用 FP16 推理
  intra_op_threads: 0                 # ONNX Runtime 内部线程数 (0=自动)
  inter_op_threads: 0
  enable_memory_arena: true
  enable_graph_optimization: true
```

## 8.6 模型加载与校验流程

```
Runtime 加载模型包:
│
├── 1. 确定模型目录
│   ├── 宿主机: /opt/ai_platform/models/{capability}/current/
│   └── 回退: /app/models/{capability}/
│
├── 2. 读取 manifest.yaml
│   └── 解析失败 → 加载失败，标记能力为 error
│
├── 3. 版本兼容性检查
│   ├── 检查 min_plugin_api_version
│   └── 不兼容 → 加载失败
│
├── 4. 文件完整性校验
│   ├── 读取 checksum.sha256
│   ├── 逐个文件计算 SHA256
│   └── 不匹配 → 加载失败 (AI_ERROR_CHECKSUM_MISMATCH)
│
├── 5. 将 manifest 信息传递给插件 init
│   ├── model_dir 路径
│   └── extra_config (包含 manifest 关键信息)
│
└── 6. 插件内部加载模型文件
    ├── 创建 ONNX Runtime Session
    └── 加载成功 → 能力就绪
```

## 8.7 模型包构建工具

提供 `model_pack` 命令行工具，用于将训练产物打包为标准模型包：

```bash
# 使用方法
model_pack create \
  --capability face_detect \
  --version v2 \
  --model model.onnx \
  --config config.yaml \
  --output ./models/face_detect/v2/

# 该工具自动:
# 1. 复制模型和配置文件
# 2. 生成 manifest.yaml (交互式填写或从模板)
# 3. 计算并生成 checksum.sha256
# 4. 校验 ONNX 模型可加载性
# 5. 可选: 运行一次推理验证
```

## 8.8 模型格式转换

从训练到部署的模型转换流水线：

```
PyTorch (.pt/.pth)
    │
    ├── torch.onnx.export() → ONNX (.onnx)
    │                              │
    │                              ├── [可选] ONNX 优化
    │                              │   └── onnxruntime.transformers.optimizer
    │                              │
    │                              ├── [可选] FP16 量化
    │                              │   └── onnxruntime.quantization
    │                              │
    │                              └── [可选] TensorRT 引擎 (.engine)
    │                                  └── trtexec --onnx=model.onnx
    │
    └── model_pack create → 标准模型包
```

## 8.9 模型版本管理

| 操作 | 说明 |
|------|------|
| **发布新版本** | 创建新目录 `v{N+1}/`，更新 `current` 软链接 |
| **回滚** | 将 `current` 软链接指向旧版本目录 |
| **清理旧版本** | 保留最近 N 个版本（默认 3），可手动删除更早版本 |
| **灰度测试** | 在宿主机目录放置新版本但不更新 `current`，通过 admin reload 指定版本测试 |
