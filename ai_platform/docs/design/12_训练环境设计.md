# 12 — 训练环境设计

## 12.1 设计目标

1. 训练在 Docker 容器中进行，环境统一可复现
2. 训练数据集存放在宿主机特定目录，通过挂载方式提供给容器
3. 训练产出的模型可通过标准化流程转换为"部署模型包"
4. 训练环境与推理环境分离（不同 Docker 镜像）
5. 为后续 Linux/Windows/ARM 多平台交付准备统一模型导出规范
6. 支持视频类能力的数据集组织与抽帧训练流程

## 12.2 训练 Docker 镜像

训练镜像与推理镜像**独立**，基于 CUDA devel 版本（包含完整编译工具链）：

```dockerfile
# Dockerfile.train — 训练环境镜像
FROM nvidia/cuda:12.2.0-cudnn8-devel-ubuntu22.04

ENV DEBIAN_FRONTEND=noninteractive

# Python + PyTorch 环境
RUN apt-get update && apt-get install -y --no-install-recommends \
    python3 python3-pip python3-dev \
    git wget curl vim \
    libopencv-dev \
    && rm -rf /var/lib/apt/lists/*

# PyTorch + 训练依赖
RUN pip3 install --no-cache-dir \
    torch==2.2.0 torchvision==0.17.0 \
    onnx==1.15.0 onnxruntime-gpu==1.17.0 \
    opencv-python-headless==4.9.0.80 \
    albumentations==1.3.1 \
    tensorboard==2.16.1 \
    pyyaml tqdm matplotlib \
    scikit-learn pandas

# 训练框架与工具
COPY train/ /app/train/
COPY tools/ /app/tools/

WORKDIR /app/train

ENTRYPOINT ["/bin/bash"]
```

## 12.4 训练容器启动

```bash
# 通用训练容器启动命令
docker run --gpus all -it --rm \
  --name ai_train_${CAPABILITY} \
  -v /data/datasets:/data/datasets:ro \          # 数据集 (只读)
  -v /data/outputs:/data/outputs \               # 训练输出 (可写)
  -v /data/pretrained:/data/pretrained:ro \       # 预训练模型
  ai-platform-train:latest \
  bash

# 示例: 训练人脸检测
docker run --gpus all -it --rm \
  --name ai_train_face_detect \
  -v /data/datasets/face_detect:/data/dataset:ro \
  -v /data/outputs/face_detect:/data/output \
  -v /data/pretrained:/data/pretrained:ro \
  -p 6006:6006 \                                  # TensorBoard
  ai-platform-train:latest \
  python3 train_face_detect.py \
    --data /data/dataset/dataset.yaml \
    --pretrained /data/pretrained/scrfd_500m.pth \
    --output /data/output \
    --epochs 120 \
    --batch-size 32 \
    --img-size 640
```

## 12.6 模型导出流程

从训练 checkpoint 到部署模型包的标准化流程：

```
训练产物 (best.pth)
    │
    ▼
┌─────────────────────┐
│ Step 1: ONNX 导出    │
│ python3 export.py    │
│   --checkpoint       │
│   --input-size 640   │
│   --opset 17         │
│   --simplify         │
│   --output model.onnx│
└─────────┬───────────┘
          │
          ▼
┌─────────────────────────┐
│ Step 2: ONNX 验证        │
│ python3 validate_onnx.py │
│   --model model.onnx     │
│   --test-images ./test/  │
│   --compare-pth best.pth │  ← 对比 PyTorch 推理结果
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│ Step 3: 可选优化          │
│ - FP16 量化              │
│ - INT8 量化 (需校准集)    │
│ - Graph 优化              │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────────┐
│ Step 4: 模型包打包            │
│ model_pack create             │
│   --capability face_detect    │
│   --version v2                │
│   --model model.onnx          │
│   --config config.yaml        │
│   --output ./models/face_detect/v2/  │
│                                │
│ 自动生成:                      │
│   manifest.yaml               │
│   checksum.sha256             │
└─────────┬───────────────────┘
          │
          ▼
┌─────────────────────────────┐
│ Step 5: 部署验证              │
│ 将模型包放入推理容器测试       │
│ 确认推理结果正确、性能达标     │
└─────────────────────────────┘
```

## 12.8 模型打包工具 (model_pack)

```python
#!/usr/bin/env python3
# tools/model_pack.py — 模型包打包工具

"""
用法:
    python3 model_pack.py create \
        --capability face_detect \
        --version v2 \
        --model /data/output/export/model.onnx \
        --config /data/output/export/config.yaml \
        --output /opt/ai_platform/models/face_detect/v2/
        
    python3 model_pack.py verify \
        --model-dir /opt/ai_platform/models/face_detect/v2/
"""

# 功能:
# 1. 复制模型文件和配置到目标目录
# 2. 读取 ONNX 模型元信息 (输入输出形状、opset 等)
# 3. 交互式或从模板生成 manifest.yaml
# 4. 计算所有文件的 SHA256 checksum
# 5. 生成 checksum.sha256 文件
# 6. 可选: 使用 ONNX Runtime 加载验证
# 7. 可选: 运行一次推理验证输出形状
```

## 12.10 多平台导出准备

虽然模型包原则上平台无关，但为了适配不同交付形态，训练导出阶段需补充以下验证：

| 目标形态 | 导出要求 |
|---------|---------|
| Linux Docker / SO | ONNX Runtime Linux x86_64 验证通过 |
| JNI | ONNX + Linux SO 接口验证通过 |
| Windows DLL | ONNX Runtime Windows x86_64 验证通过 |
| ARM64 | ONNX Runtime ARM64 可加载性验证（条件具备时） |

建议在模型发布前至少完成：

- **x86_64 Linux 验证**
- **Windows 可加载性验证**（如目标能力需交付 Windows）
- **视频能力抽帧一致性验证**（如 deepfake_detect）
