# 15 — 错误码与日志规范

## 15.1 统一错误码体系

### 15.1.1 错误码分段

| 范围 | 分类 | 说明 |
|------|------|------|
| `0` | 成功 | 操作成功 |
| `-1 ~ -99` | 通用错误 | 参数/句柄/内存等通用错误 |
| `-100 ~ -199` | 插件层错误 | 模型加载/推理/预处理等 |
| `-200 ~ -299` | Runtime 层错误 | 实例池/调度/reload 等 |
| `-300 ~ -399` | HTTP 服务层错误 | 路由/参数/认证等 |
| `-400 ~ -499` | 授权错误 | License 相关 |
| `-500 ~ -599` | 系统错误 | 文件/网络/设备等 |

### 15.1.2 完整错误码定义

```c
// ai_error_codes.h

#ifndef AI_ERROR_CODES_H
#define AI_ERROR_CODES_H

// ==== 成功 ====
#define AI_OK                           0

// ==== 通用错误 (-1 ~ -99) ====
#define AI_ERR_UNKNOWN                  -1    // 未知错误
#define AI_ERR_INVALID_PARAM            -2    // 参数无效
#define AI_ERR_INVALID_HANDLE           -3    // 句柄无效
#define AI_ERR_INIT_FAILED              -4    // 初始化失败
#define AI_ERR_NOT_INITIALIZED          -5    // 未初始化
#define AI_ERR_ALREADY_INITIALIZED      -6    // 重复初始化
#define AI_ERR_OUT_OF_MEMORY            -7    // 内存不足
#define AI_ERR_TIMEOUT                  -8    // 超时
#define AI_ERR_UNSUPPORTED              -9    // 不支持的操作
#define AI_ERR_INTERNAL                 -10   // 内部错误

// ==== 插件层错误 (-100 ~ -199) ====
#define AI_ERR_MODEL_LOAD_FAILED        -100  // 模型加载失败
#define AI_ERR_MODEL_NOT_FOUND          -101  // 模型文件不存在
#define AI_ERR_MODEL_CHECKSUM           -102  // 模型校验和不匹配
#define AI_ERR_MODEL_INCOMPATIBLE       -103  // 模型版本不兼容
#define AI_ERR_INFER_FAILED             -110  // 推理执行失败
#define AI_ERR_INFER_TIMEOUT            -111  // 推理超时
#define AI_ERR_IMAGE_DECODE             -120  // 图像解码失败
#define AI_ERR_IMAGE_INVALID            -121  // 图像格式无效
#define AI_ERR_IMAGE_TOO_SMALL          -122  // 图像尺寸过小
#define AI_ERR_IMAGE_TOO_LARGE          -123  // 图像尺寸过大
#define AI_ERR_PREPROCESS_FAILED        -130  // 预处理失败
#define AI_ERR_POSTPROCESS_FAILED       -131  // 后处理失败
#define AI_ERR_MANIFEST_INVALID         -140  // manifest.yaml 无效
#define AI_ERR_CONFIG_INVALID           -141  // config.yaml 无效
#define AI_ERR_RELOAD_FAILED            -150  // 插件重新加载失败

// ==== Runtime 层错误 (-200 ~ -299) ====
#define AI_ERR_CAPABILITY_NOT_FOUND     -200  // 能力不存在
#define AI_ERR_CAPABILITY_DISABLED      -201  // 能力已禁用
#define AI_ERR_CAPABILITY_ERROR         -202  // 能力异常状态
#define AI_ERR_CAPABILITY_RELOADING     -203  // 能力正在更新中
#define AI_ERR_POOL_EXHAUSTED           -210  // 实例池耗尽(无可用实例)
#define AI_ERR_POOL_TIMEOUT             -211  // 等待实例池超时
#define AI_ERR_PLUGIN_LOAD_FAILED       -220  // 插件 SO 加载失败
#define AI_ERR_PLUGIN_SYMBOL_MISSING    -221  // 插件缺少必需符号
#define AI_ERR_PLUGIN_VERSION_MISMATCH  -222  // 插件 API 版本不匹配
#define AI_ERR_RELOAD_DRAIN_TIMEOUT     -230  // Reload 等待排空超时
#define AI_ERR_RELOAD_ROLLBACK          -231  // Reload 失败已回滚
#define AI_ERR_ROLLBACK_FAILED          -232  // 回滚失败
#define AI_ERR_ROLLBACK_NO_HISTORY      -233  // 无可回滚的版本

// ==== HTTP 服务层错误 (-300 ~ -399) ====
#define AI_ERR_BAD_REQUEST              -300  // 请求格式错误
#define AI_ERR_MISSING_FIELD            -301  // 缺少必填字段
#define AI_ERR_INVALID_JSON             -302  // JSON 解析失败
#define AI_ERR_IMAGE_FIELD_EMPTY        -303  // 图像字段为空
#define AI_ERR_BASE64_DECODE            -304  // Base64 解码失败
#define AI_ERR_BODY_TOO_LARGE           -305  // 请求体过大
#define AI_ERR_ADMIN_AUTH_FAILED        -310  // 管理接口认证失败
#define AI_ERR_ADMIN_TOKEN_MISSING      -311  // 缺少管理令牌
#define AI_ERR_RATE_LIMITED             -320  // 请求频率超限

// ==== 授权错误 (-400 ~ -499) ====
#define AI_ERR_LICENSE_NOT_FOUND        -400  // License 文件不存在
#define AI_ERR_LICENSE_INVALID          -401  // License 无效
#define AI_ERR_LICENSE_EXPIRED          -402  // License 已过期
#define AI_ERR_LICENSE_SIGNATURE        -403  // License 签名验证失败
#define AI_ERR_LICENSE_MACHINE          -404  // 机器指纹不匹配
#define AI_ERR_LICENSE_CAPABILITY       -405  // 能力未授权
#define AI_ERR_LICENSE_VERSION          -406  // 平台版本不在授权范围
#define AI_ERR_LICENSE_PARSE            -407  // License 解析失败
#define AI_ERR_LICENSE_GRACE_PERIOD     -408  // License 宽限期 (警告级)
#define AI_ERR_FINGERPRINT_NOT_FOUND    -410  // 机器指纹文件不存在
#define AI_ERR_FINGERPRINT_READ         -411  // 机器指纹读取失败

// ==== 系统错误 (-500 ~ -599) ====
#define AI_ERR_FILE_NOT_FOUND           -500  // 文件不存在
#define AI_ERR_FILE_READ                -501  // 文件读取失败
#define AI_ERR_FILE_WRITE               -502  // 文件写入失败
#define AI_ERR_DIR_NOT_FOUND            -503  // 目录不存在
#define AI_ERR_DEVICE_NOT_AVAILABLE     -510  // GPU 设备不可用
#define AI_ERR_DEVICE_OUT_OF_MEMORY     -511  // GPU 显存不足
#define AI_ERR_CUDA_ERROR               -512  // CUDA 运行时错误

#endif // AI_ERROR_CODES_H
```

### 15.1.3 HTTP 状态码映射

| AI 错误码范围 | HTTP 状态码 | 说明 |
|--------------|-----------|------|
| `0` | `200` | 成功 |
| `-1 ~ -10` | `400` / `500` | 视具体错误 |
| `-100 ~ -149` | `500` | 服务端错误 |
| `-150` | `500` | Reload 失败 |
| `-200 ~ -203` | `404` / `503` | 能力不可用 |
| `-210 ~ -211` | `503` | 服务繁忙 |
| `-220 ~ -222` | `500` | 服务端错误 |
| `-300 ~ -305` | `400` | 客户端请求错误 |
| `-310 ~ -311` | `401` | 未认证 |
| `-320` | `429` | 频率限制 |
| `-400 ~ -408` | `403` | 授权禁止 |
| `-500 ~ -512` | `500` | 服务端错误 |

## 15.2 日志规范

### 15.2.1 日志级别

| 级别 | 用途 | 示例 |
|------|------|------|
| **TRACE** | 极详细调试信息 | 张量数据、像素值 |
| **DEBUG** | 调试信息 | 函数入口参数、中间变量 |
| **INFO** | 正常运行信息 | 启动完成、能力加载、请求处理 |
| **WARN** | 警告（不影响运行） | License 即将过期、指纹部分匹配 |
| **ERROR** | 错误（影响单次请求） | 推理失败、参数错误 |
| **CRITICAL** | 严重错误（影响整体服务） | License 失效、插件崩溃 |

### 15.2.3 日志文件分类

| 日志文件 | 内容 | 保留策略 |
|---------|------|---------|
| `platform.log` | 主服务日志 (INFO+) | 100MB/文件, 保留 10 个 |
| `platform_debug.log` | 调试日志 (DEBUG+, 可选开启) | 50MB/文件, 保留 5 个 |
| `access.log` | HTTP 访问日志 | 100MB/文件, 保留 10 个 |
| `audit.log` | 授权审计日志 | 不自动清理, 长期保留 |

### 15.2.5 spdlog 配置示例

```cpp
#include <spdlog/spdlog.h>
#include <spdlog/sinks/rotating_file_sink.h>
#include <spdlog/sinks/stdout_color_sinks.h>

void setup_logging(const LogConfig& config) {
    // 控制台输出
    auto console_sink = std::make_shared<spdlog::sinks::stdout_color_sink_mt>();
    console_sink->set_level(spdlog::level::info);
    
    // 主日志文件 (轮转)
    auto file_sink = std::make_shared<spdlog::sinks::rotating_file_sink_mt>(
        config.log_file, 
        config.max_size_mb * 1024 * 1024, 
        config.max_files
    );
    file_sink->set_level(spdlog::level::from_str(config.level));
    
    // 创建 logger
    auto logger = std::make_shared<spdlog::logger>(
        "platform", 
        spdlog::sinks_init_list{console_sink, file_sink}
    );
    
    // 格式: [时间] [级别] [模块] 消息
    logger->set_pattern("[%Y-%m-%dT%H:%M:%S.%e%z] [%-5l] [%-8n] %v");
    
    spdlog::set_default_logger(logger);
    spdlog::flush_every(std::chrono::seconds(3));
}
```

## 15.3 统一 API 响应格式规范

### 15.3.1 成功响应

```json
{
    "code": 0,
    "message": "success",
    "data": { ... },
    "request_id": "req_20260326_a1b2c3d4",
    "cost_ms": 42.5,
    "api_version": "v1"
}
```

```json
{
    "code": -200,
    "message": "Capability not found: unknown_capability",
    "data": null,
    "request_id": "req_20260326_e5f6g7h8",

```
