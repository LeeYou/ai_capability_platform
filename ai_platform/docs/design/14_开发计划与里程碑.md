## 14.6 关键依赖与风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| **模型精度不达标** | 能力不可用 | 提前准备 2-3 个备选模型；使用公开预训练模型验证流程 |
| **GPU 显存不足** | 并发能力受限 | 动态调整实例池大小；支持共享 Session 模式 |
| **ONNX Runtime 兼容性** | 模型加载失败 | 锁定 ONNX Runtime 版本；导出时验证 |
| **客户环境差异** | 部署失败 | 完善 CPU fallback；详细部署文档 |
| **License 被破解** | 授权失效 | 二进制混淆(可选)；公钥嵌入；双层校验 |
| **多平台差异** | Windows/ARM 构建失败 | 统一 C ABI；分平台 CI；减少平台专有依赖 |
| **视频输入过大** | 请求超时/内存压力 | 增加视频大小限制、抽帧策略、异步扩展预留 |
